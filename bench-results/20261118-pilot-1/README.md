# Pilot campaign 20261118-pilot-1 (MEM-7, issue #123)
Machine: M1


Pilot measurement of the MEM-A port (generalization gate): the
`alea-lcg` / `philosophers` / `window` workloads of the confrontation
runner, one JSON line per measurement (VmHWM `rss_max_ko`, `temps_ms`,
node counts `noeuds`, cross-check `verifie`), protocol
`docs/bench-confrontation-witnesses-and-measures.md`.

## Exact reproduction command

```bash
cargo build --release -p lisage-bench --bin confrontation
docker build -t lisage-oxidd:latest docker/oxidd
uv run python -m scripts bench-confrontation --pilot --repetitions 5 --run-id 20261118-pilot-1
```

(machine: WSL2 local developer machine, 2026-11-18; OxiDD pinned at
commit `c7a458df8b747a3ee44d0e9e61059a1621865fcd`; one fresh process per
measurement for lisage, one fresh container per measurement for OxiDD).

The randomized IDs are reproducible by construction: the `alea-lcg`
charge is the deterministic LCG of `SEED_LCG` (same LCG as the M1-8
baseline), and the `philosophers` states file is versioned in
`crates/lisage-bench/models/philosophers-n5-states.txt` (generated by the
same algorithm as `etats_etendus` in `tests/confrontation.rs`, validated
against the pinned |R_n| for n = 3..7).

## Contents

- `<charge>-<outil>.jsonl`: one JSON line per repetition (raw).
- `aggregats.json`: median/min/max of `temps_ms` and `rss_max_ko` per
  charge x tool, plus the constant cross-check values `noeuds`/`verifie`
  and the cross-tool `divergences` list (empty: the campaign is valid).
- `REPORT.md`: the measured values and the written decision.
