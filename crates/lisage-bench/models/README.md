# Real benchmark inputs (M7-4, issue #114)

Versioned inputs for the real (non-toy) confrontation workloads. Each file
is a real, documented benchmark model; the cross-check value (BDD node
count of the charge) is pinned in `tests/confrontation.rs`.

| File | Source | Charge |
|---|---|---|
| `uf20-01.cnf` | SATLIB `uf20-91` set (20 vars, 91 clauses, phase-transition 3-SAT, generated by `mcnf`), University of British Columbia, https://www.cs.ubc.ca/~hoos/SATLIB/benchm.html — retrieved from the `splr` 0.19.0 crate `cnfs/` directory (crates.io) | `cnf` workload: BDD of the CNF function |
| `SwimmingPool-1.pnml` | Model Checking Contest model `SwimmingPool-PT-01` (9 places, 7 transitions), https://mcc.lip6.fr — via the `evangelista/mcc-models` mirror (depot.lipn.univ-paris13.fr) | `pnml` workload: BDD of the transition relation over 2p variables |
| `erk-000001.pnml` | Model Checking Contest model `ERK-PT-000001` (11 places, 11 transitions), https://mcc.lip6.fr — same mirror | `pnml` workload: BDD of the transition relation over 2p variables (22 variables, heavy: pinned in an `#[ignore]`d test) |

The `pnml` charge builds the transition relation of the P/T net (1-safe
models, unit arc weights) as a Boolean function over `2p` variables
(`x_0..x_{p-1}` current marking, `x'_0..x'_{p-1}` next marking), serialized
for the external witnesses as a truth table in the standard stdin format
(`n` then `2^n` values `0`/`1`) consumed by `cudd_count` / `oxidd_count`.
